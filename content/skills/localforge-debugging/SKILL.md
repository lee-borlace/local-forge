---
name: localforge-debugging
description: Diagnose a bug or repeated failure using a short evidence-first workflow.
---
Record expected and actual behaviour. Reproduce if an existing safe mechanism is available. Trace the smallest relevant path using symbol tools. Keep findings and ruled-out hypotheses in lf_task. Identify the cause before editing. Make one targeted change; run relevant verification. If the same failure recurs, change the hypothesis instead of repeating actions. If blocked, report evidence and the missing capability. Do not silently weaken tests.
